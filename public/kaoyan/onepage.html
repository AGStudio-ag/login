  • 秋收起义 / 南昌起义的旗帜 → 工农革命军 / 国民革命军
  • 党对军队的绝对领导 → 发端于南昌起义、奠基于三湾改编、定型于古田会议
  • 长征的直接原因 / 最壮烈最关键一仗 → 第五次反「围剿」失败 / 湘江战役
  • 抗战时间轴 → 1931 九一八局部抗战起点；1936 西安事变和平解决十年内战基本结束；1937 七七进入全民族抗战

  • 游击战地位 → 战略防御阶段正面战场正规战为主；战略相持阶段敌后游击战成为主要作战方式

  • 延安整风 → 重点是教条主义；最主要任务反对主观主义以整顿学风；方针惩前毖后、治病救人
  • 战略进攻序幕 / 深厚群众基础 → 三路大军相互策应 / 土地制度改革
  • 1947 米脂县杨家沟会议 / 1949 进驻香山 → 两个转折点 / 革命重心由农村转向城市
  • 三大外交政策 / 三反运动 → 一边倒、另起炉灶、打扫干净屋子再请客 / 反贪污、反浪费、反官僚主义
  • 新民主主义社会的阶级构成 → 工人阶级、农民阶级、小资产阶级、民族资产阶级（工农小民）

  • 中国进入社会主义社会最主要的标志 → 社会主义经济制度的确立（不是政治制度）
  • 四个统一战线 → 国民革命联合战线、工农民主统一战线、抗日民族统一战线、人民民主统一战线

⑧ 排错九法（一句话版）

  • 1. 绝对极端说法 · 墓碑词：唯一 / 一切 / 任何 / 总是 / 完全 / 绝对 / 所有 / 只能 / 无限制 / 一成不变 —— 出现即高危。
  • 2. 不合题意：选项本身正确，但不回答题干所问；「国内上升到国外」是典型变体。
  • 3. 课堂临时举例：题干给的具体例子只是材料，不能由此推出普遍性结论。
  • 4. 唯心主义：把观念、经验、感觉当成世界本原或决定力量。
  • 5. 三项解题法 · 盯住目标：先定「问什么」，再排除答非所问的干扰项。
  • 6. 时态问题：已经 / 正在 / 将要 / 尚未 / 开始 / 完成 与历史阶段不符即错。

  • 8. 美国相关：涉及美国 / 西方的评价要站稳立场，警惕「唯一模式」「历史终结」式表述。
